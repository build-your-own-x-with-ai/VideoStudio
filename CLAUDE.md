# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Overview

This directory contains documentation for Elecard video stream analysis tools. There is no source code in this repository - only PDF reference materials.

## Available Documentation

- **Elecard_Analyzers_zh_Datasheet.pdf** - Chinese language datasheet for Elecard Analyzers suite
- **EStreamAnalyzer_UG_Mac.pdf** - User guide for EStream Analyzer on macOS
- **EStreamEye_UG_Mac.pdf** - User guide for EStream Eye on macOS

## Tools

These are professional video stream analysis and debugging tools used for:
- Video codec analysis (H.264, H.265/HEVC, VP9, AV1, etc.)
- Stream validation and quality assessment
- Bitrate and frame analysis
- Transport stream inspection

## Working with PDFs

Use the Read tool with the `pages` parameter to extract specific sections from these PDFs when needed (e.g., `pages: "1-5"` for the first 5 pages).
